# My Portfolio

Personal portfolio website with a blueprint/schematic-themed design, showcasing my projects and skills as a Full-Stack Developer.

## 🚀 Features
- Blueprint/schematic-inspired visual theme
- Working live demos of projects: QuickFix AI Triage, WanderWorld, GHOST SITES
- Two visual style versions: minimal warm-white & dark terminal-aesthetic
- Responsive design across devices

## 🛠️ Tech Stack
- HTML, CSS, JavaScript

## ⚙️ Installation
```bash
git clone https://github.com/jothishajo39-ux/Myportfolio.git
cd Myportfolio
```
Open `index.html` in your browser.
